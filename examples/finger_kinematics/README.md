# Finger Kinematics from EMG

Train regression models to predict continuous finger joint angles from EMG signals.

## Overview

This pipeline demonstrates EMG-to-kinematics regression for continuous finger movement tracking. Unlike discrete gesture classification, this predicts exact joint angle values in real-time.

**Use Cases:**
- Prosthetic hand control with proportional movement
- Real-time finger tracking for VR/AR applications
- Biomechanics research and rehabilitation monitoring

## Installation

```bash
# Core package
pip install python-intan

# Optional: For video landmark extraction (Step 2)
pip install 'python-intan[video]'
```

## Pipeline Overview

The pipeline consists of 8 scripts that must be run in order:

1. **`1_synchronize_emg_video.py`** - ⚠️ CRITICAL: Align EMG and video timestamps
2. **`2_extract_joint_angles.py`** - Extract hand landmarks and joint angles from video
3. **`3_calibrate_and_normalize.py`** - (Optional) Normalize EMG signals for consistent training
4. **`4_build_dataset.py`** - Build synchronized EMG feature → joint angle dataset
5. **`5_train_model.py`** - Train neural network regression model
6. **`6_predict.py`** - Predict joint angles from new EMG recordings
7. **`7_analyze_predictions.py`** - (Optional) Generate diagnostic plots and metrics
8. **`8_render_prediction_video.py`** - (Optional) Create annotated video with predictions

## Quick Start

```bash
# Step 1: MUST RUN FIRST - Synchronize EMG and video timestamps
python 1_synchronize_emg_video.py batch --root_dir /path/to/data --verbose

# Step 2: Extract joint angles from video files
python 2_extract_joint_angles.py  # Opens file picker dialog

# Step 3: (Optional) Calibrate EMG for normalization
python 3_calibrate_and_normalize.py --root_dir /path/to/data

# Step 4: Build training dataset with synchronized timestamps
python 4_build_dataset.py --root_dir /path/to/data --multi_file

# Step 5: Train the regression model
python 5_train_model.py --root_dir /path/to/data --epochs 200 --use_pca

# Step 6: Make predictions on new data
python 6_predict.py file --file_path test.rhd --angles_file test_angles.csv --smooth --plot

# Step 7: (Optional) Analyze prediction quality
python 7_analyze_predictions.py --pred_file predictions.txt --angles_file angles.csv

# Step 8: (Optional) Render annotated video
python 8_render_prediction_video.py --video test.mp4 --pred predictions.txt --landmarks landmarks.npz --show_errors
```

## ⚠️ Critical: Synchronization

**Always run Step 1 first!** EMG and video recordings start at different times (observed offsets up to 9+ seconds). Without synchronization, EMG features will be matched with incorrect joint angle labels, causing model training to fail.

See **[SYNCHRONIZATION.md](SYNCHRONIZATION.md)** for detailed documentation.

## Directory Structure

Your project should be organized as follows:

```
project_root/
├── raw/                    # EMG recordings (.rhd, .rhs, .npz, .csv, .poly5)
│   └── recording_001.rhd
├── videos/                 # Source videos for landmark extraction  
│   └── recording_001.mp4
├── sync/                   # ⚠️ Generated by Step 1 (REQUIRED before Step 4)
│   └── recording_001_sync.json
├── media/landmarks/        # Generated by Step 2
│   ├── recording_001_landmarks.npz
│   └── recording_001_angles.csv
├── calibration/            # (Optional) Generated by Step 3
│   └── calibration.npz
├── dataset/                # Generated by Step 4
│   └── kinematics_dataset.npz
└── model/                  # Generated by Step 5
    ├── model.pth
    ├── scaler.pkl
    ├── pca.pkl (if using PCA)
    ├── metadata.json
    └── metrics.json
```

## Key Features

### Automatic Synchronization
- Cross-correlation-based timestamp alignment
- Handles independent start/stop times for EMG and video
- Saves offsets in `sync/` directory for reproducible alignment

### Feature Extraction
- Time-domain EMG features: RMS, MAV, VAR, ZC, SSC, WL, IEMG
- Configurable sliding window (default: 200ms window, 50ms step)
- Optional PCA dimensionality reduction

### Joint Angle Prediction
- Multi-output regression (5 joints: thumb, index, middle, ring, pinky)
- Kalman smoothing for stable predictions
- Real-time capable with PyTorch

### Model Training
- Early stopping with patience monitoring
- Automatic train/validation split
- Metrics: MSE, MAE, R² per joint
- GPU acceleration support

## Common Issues

### "No sync file found" Error
**Solution:** Run Step 1 (`1_synchronize_emg_video.py batch`) before building datasets.

### Poor Prediction Accuracy
- Check synchronization confidence scores (should be >0.3)
- Verify joint angle CSV timestamps match video duration
- Ensure calibration was applied if model was trained on normalized data
- Try increasing training epochs or using PCA


## File Naming Conventions

For multi-file processing, joint angle files should match EMG filenames:
- EMG: `raw/recording_001.rhd`
- Angles: `media/landmarks/recording_001_angles.csv` (auto-generated by Step 2)

Custom angle files can be placed in:
- `media/landmarks/`
- `joint_angles/`
- Or specify with `--angles_dir` parameter

## Example Workflow

Complete workflow with 3 recordings:

```bash
# Setup directory structure
mkdir -p ~/emg_kinematics/{raw,joint_angles}

# Copy data
cp recording_*.rhd ~/emg_kinematics/raw/
cp angles_*.csv ~/emg_kinematics/joint_angles/

# Build dataset
cd examples/finger_kinematics
python 2_build_dataset.py \
    --root_dir ~/emg_kinematics \
    --multi_file \
    --window_ms 200 \
    --step_ms 50

# Train model
python 3_train_model.py \
    --root_dir ~/emg_kinematics \
    --use_pca \
    --pca_variance 0.95 \
    --epochs 150

# Test on new recording
python 4_predict.py file \
    --file_path ~/emg_kinematics/raw/test_recording.rhd \
    --angles_file ~/emg_kinematics/joint_angles/test_recording_angles.csv \
    --plot
```
